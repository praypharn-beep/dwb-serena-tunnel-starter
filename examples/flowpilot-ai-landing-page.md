# FlowPilot AI Landing Page Test Prompt

This is the prompt used to test the ChatGPT + Serena local workspace workflow in the Dev with Bebz demo.

Copy the prompt below into ChatGPT after your Serena tunnel is connected and a local project is active.

---

Create a modern, responsive landing page for a fictional AI productivity platform called **FlowPilot AI**.

The website should feel like a polished SaaS product, not a generic template.

### Requirements

- Use a clean, modern dark theme.
- Fully responsive for desktop, tablet, and mobile.
- Create a sticky navigation bar with:
  - Logo: FlowPilot AI
  - Features
  - How It Works
  - Pricing
  - Sign In
  - Get Started button

### Hero Section

Create a strong hero section with:

**Headline:**
“Turn ideas into action with AI.”

**Subheadline:**
“Plan projects, automate repetitive work, and keep your team moving with one intelligent workspace.”

Include:

- “Start for Free” primary CTA
- “Watch Demo” secondary CTA
- A visually interesting dashboard preview or abstract AI workspace illustration

### Features Section

Create 4 feature cards:

1. AI Project Planning
2. Smart Task Automation
3. Team Collaboration
4. Real-Time Insights

Each card should include an icon, title, and short description.

### How It Works

Create a simple 3-step section:

1. Describe your goal
2. Let AI build the workflow
3. Review and execute

Make the steps visually connected.

### Dashboard Preview

Add a product dashboard section showing:

- Project progress
- Tasks
- Team members
- AI suggestions
- Activity timeline

Use mock data.

### Pricing

Create 3 pricing plans:

- Starter — Free
- Pro — $19/month
- Team — $49/month

Highlight the Pro plan as the recommended option.

### Testimonials

Add 3 fictional customer testimonials with names, roles, and avatars.

### Final CTA

Add a strong call-to-action section:

“Ready to work smarter?”

Button:
“Start Building for Free”

### Footer

Include:

- Product
- Company
- Resources
- Legal
- Social links

### Design Direction

Use:

- Dark navy background
- Blue/cyan accent colors
- Subtle gradients
- Rounded cards
- Soft shadows
- Modern typography
- Smooth hover effects
- Subtle scroll animations

Avoid excessive animations or visual clutter.

The final result should look like a production-quality SaaS landing page suitable for a real startup.

Use reusable components and keep the code clean, organized, and easy to maintain.
